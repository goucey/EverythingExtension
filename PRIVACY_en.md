# Privacy Notice
The official release of this software does not collect any user private information. This privacy guarantee does not apply to variants redistributed by third parties based on open-source code. If you have privacy concerns, you may choose not to install or use this application.

### Dependency Description
This application depends on the locally installed Everything program. The EverythingExt plugin empowers the command palette with high-speed file search and shortcut command functions.
The app only invokes Everything’s native local API when you manually perform search actions. It never calls Everything silently in the background, scans files automatically, or uploads filenames/file paths retrieved from Everything to external servers without user consent.

### Third-Party Services Statement
1. This software relies on the local third-party program Everything and its components to work properly. Everything is maintained by independent developers and governed by its own privacy policy.
2. We have no control over Everything’s data collection, disk access, network requests or logging behaviors. Everything’s file indexing, disk scanning and logging rules are determined solely by Everything’s own configuration.
3. This application only receives local search results passively from Everything. It never collects, caches, uploads or forwards any file information obtained via Everything to remote servers.
4. You retain full control: you may quit or uninstall Everything at any time, or disable indexing, permissions and network access inside Everything’s settings to cut off all interaction between our app and Everything.
